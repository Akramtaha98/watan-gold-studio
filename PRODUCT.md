# WATAN Gold Studio
A local, single-app Streamlit tool for Malay corpus maintainers to upload, mask, verify with Qwen 3, review exceptions and export four canonical governance tables and exact trainer/index/evaluation JSONL projections. User-specified WaRiSAN identity is configurable policy, not independently established institutional fact. Original uploaded bytes are never written to disk by this application. Corpus state is session-local. Native Streamlit controls, a guided three-step wizard and dedicated PTSL-only workspace and restrained teal preserve the existing WATAN operational style. No simulated inference in the application.
